# Blinkit-Analysis-In-Python
#  Blinkit Sales Analysis using Python

This project demonstrates an end-to-end data analysis workflow using **Python, Pandas, NumPy, Matplotlib, and Seaborn** to analyze Blinkit's retail sales data and generate actionable business insights. The project focuses on data cleaning, exploratory data analysis (EDA), KPI calculation, and visualization to identify sales trends, product performance, and outlet characteristics.

---

# 📌 Project Overview

The objective of this project is to transform raw Blinkit sales data into meaningful business insights through data preprocessing, exploratory analysis, KPI generation, and visualization.

### ✅ Data Cleaning & Transformation (Python)
- Imported and explored the dataset using Pandas.
- Cleaned inconsistent values and standardized categorical data.
- Validated data types and prepared the dataset for analysis.

### ✅ Data Analysis (Python)
- Calculated key business KPIs including Total Sales, Average Sales, Total Items Sold, and Average Rating.
- Performed exploratory data analysis using Pandas and NumPy.
- Analyzed sales trends across item types, outlet locations, outlet sizes, and establishment years.

### ✅ Data Visualization (Matplotlib & Seaborn)
Developed insightful visualizations including:
- Sales by Fat Content
- Sales by Item Type
- Sales by Outlet Tier
- Sales by Outlet Establishment Year
- Sales by Outlet Size
- Sales by Outlet Location Type

### ✅ Business Insights
- Identified top-performing product categories by total sales.
- Compared sales across different outlet tiers and outlet sizes.
- Evaluated sales trends based on outlet establishment year.
- Analyzed customer preferences for low-fat and regular products to support inventory and business planning.
